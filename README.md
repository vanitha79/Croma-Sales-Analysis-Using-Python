
# Croma Sales Analytics Dashboard

## Project Overview
This project is an interactive sales analytics dashboard developed using Python and Streamlit to analyze Croma sales data. The dashboard provides business insights through KPIs, filters, charts, and visualizations.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- NumPy

## Dashboard Features
- Interactive Dashboard
- Category-wise Sales Analysis
- Product-wise Performance Analysis
- Customer Insights
- State-wise Sales Analysis
- Dynamic Filtering
- KPI Tracking

## Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value

## Business Insights
- Identified top-performing products
- Analyzed category-wise sales trends
- Evaluated customer purchasing behavior
- Compared sales performance across locations
